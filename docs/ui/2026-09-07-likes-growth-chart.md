# 支持页增长曲线

## 变更记录

| 时间 | 说明 |
|------|------|
| 2026-09-07 | 在 QQ 群区块后增加喜欢人数曲线与时间窗按钮 |
| 2026-09-07 | 时间窗改为 1 周、1 月、半年、1 年、全部 |
| 2026-09-07 | 区块标题改为「增长曲线」，去掉说明句 |
| 2026-09-07 | 默认时间窗改为 1 月 |

## 背景信息

人数只出现在页顶一句文案里，看不出增长过程。需要一张和 GitHub star 历史类似的累计曲线，并用一周到全部的窗口只改变横轴范围。

## 当前方案

主列最底部一节「增长曲线」，无说明文案。右侧胶囊按钮：1 周、1 月、半年、1 年、全部；默认选中 1 月，选中项深底浅字。下方 SVG 面积图：心形粉描边与浅填充、横向网格、左纵轴、底横轴。悬停出现竖虚线、圆点和气泡（本地时间 + 累计人数）。窄屏时按钮换到标题下方。无新事件时是水平线；「全部」纵轴从 0 起，其余窗口放大可见区间，避免基数很大时看不出近期变化。

## 其他模块引用约束

曲线只读首页下发的累计人数与事件时间戳，不在前端再计一次喜欢。

## 工程师测试验收方法

桌面与窄屏都要看到标题「增长曲线」、五个时间按钮和完整横轴，没有 GitHub 说明句。首次打开默认选中「1 月」，横轴约最近 30 天。切换按钮后选中态与刻度同步变化。悬停或点按曲线出现人数气泡。收款码、QQ 群与页顶人数文案保持原样。
